Step 2: Commit to Git & Push to GitHub
Now, tie everything together with Git and push your project to GitHub (combining your skills from Assignments 1.4 and 1.5):

Open your terminal inside your project folder.

Initialize or check your Git status:

Bash
git status
Stage, commit, and push your final mini-project:

Bash
git add index.html
git commit -m "Complete Assignment 2.5: HTML Foundations Mini-Project"
git push origin main
